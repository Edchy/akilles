# Workout flow redesign

Branch: `redesign/workout-core`, based on `83ca871` (Claude’s swipeable cards).

The core loop is Today → Start → swipe between cards → log the work → Finish.
Plan edits future workouts. Profile holds progress, history and settings.

## Decisions implemented

Paused workouts remain in their position, with a faded row. Their rotation still
excludes them. Display order persists separately so reordering and resuming work.
Swipe Options collects copying, choosing what is next and pausing. The editor is
for the workout’s contents, in session order.

Exercise creation comes before long lists. “Available exercises” replaces
“library”; hiding an exercise keeps its history. Shared weights and progression
steps explain their scope. Session notes override the usual exercise note without
rewriting it, and disappear when that session ends.

Cardio uses direct entry for arbitrary targets and results, including exact times.
Last time is a comparison, never prefilled as today’s result. The score requires
entry before Done. Permanent target changes belong in Plan. The record key still
includes machine and target so comparisons remain meaningful; this implementation
detail no longer occupies the training screen.

The title-only card was an intentional distant-card placeholder. Cards now mount
with their full content, with offscreen illustrations held still. A stretch routine
pauses when its card is left.

## Put aside

The separate Paused section, repeated workout actions inside the editor, permanent
save choices during cardio, score steppers, repeated personal-record statistics,
and warm-up/cardio coaching paragraphs have been removed from this flow.
Permanent deletion of paused workouts is put aside; pausing is reversible.
Onboarding, progression rules, training history and existing artwork are preserved.

## Still needs a device review

This is the first working simplification, not a finished visual redesign. Review
card spacing and keyboard behaviour on an iPhone, swipe versus reorder gestures,
VoiceOver actions, and large exercise lists. Full card mounting also needs a
performance check with unusually long workouts. Exercise swipe actions remain
undecided; editing is still reached by tapping an exercise.
